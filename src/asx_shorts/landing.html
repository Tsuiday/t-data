Built to be trusted in a pipeline

Each rule below is documented, tested and applied the same way to every row, from the first file in 2006 to this morning's.

01 · Recomputed, not copied

One short % formula across every ASIC format

ASIC's files switched from UTF-16 tabs to UTF-8 commas in 2022 and changed their percentage scaling more than once. Short % is always short positions ÷ shares on issue, so a 2011 row compares with a 2026 row.

02 · Honest dates

Position date on every row, gaps recorded as gaps

ASIC publishes each date about four trading days later. A day with no report is stored as "no report", never filled from the day before. Rows that fail basic sanity checks are dropped, not patched.

03 · Purchases, not paperwork

Buying screens count decisions to buy

Only open-market purchases (code P on shares) count as buying. Grants, tax withholding and option exercises are kept, but never mistaken for conviction. A trade listed under several owners is counted once.

04 · Reconciled daily

Daily filings match the SEC's quarterly files exactly

New EDGAR filings load each day; when the SEC's quarterly data set arrives, its rows replace the daily ones identically. Verified on real filings across Forms 3, 4 and 5 before launch.
